# Balanced building colour mockups — round 3

Generated October 8, 2026 with the built-in image-generation workflow. These
are visual-direction mockups only; no runtime assets were edited.

The prompt used each original sprite as the edit target and the first two rounds
as colour-intensity references. The target was a midpoint: one dominant colour,
one neutral building material, and one restrained accent.

Left to right:

- Temple: burnished vermilion/ivory; deep jade/cream; softened indigo/sandstone.
- Chateau: dusty royal blue/limestone; muted terracotta/warm stone; deep
  teal/blush limestone.
- Shopping mall: steel blue/silver with coral entrance; petrol teal/cream with
  copper entrance; plum-slate/ivory with muted brass entrance.

The temple concepts remain candidates for Lilycove palettes 10/11 and the
Chateau/mall concepts for Liesma palette 6, subject to a fresh full audit before
implementation. Generated images are not indexed or pixel-exact; rebuild any
selected look from the original sprite and verified hardware colours.
